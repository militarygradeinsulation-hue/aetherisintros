# Align Simple Mode with the main Aetheris interface

## Goal
Make Simple Mode feel native to the signed-in Aetheris site while preserving its current information and working actions.

## Changes
- Replace the isolated ledger styling with the main site’s near-black, graphite, ivory, cobalt-action, and restrained amber-signal palette.
- Use the same editorial serif headings, interface type, hairline borders, button shapes, spacing, and panel treatment as the surrounding website.
- Keep the Simple Mode layout, live data, search, profile links, messages, intro requests, needs, Memory, Insights, and conversations unchanged.
- Retain amber only for genuine relationship signals; use cobalt for actions and selected states like the rest of the site.

## Verification
- Compare Simple Mode with adjacent signed-in pages on desktop and mobile.
- Check search and representative profile, message, intro, need, and conversation actions.
- Confirm no clipping, overflow, browser errors, or build errors.
