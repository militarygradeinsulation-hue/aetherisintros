# Combine the supplied interaction style with Ask Intros

## Goal
Bring the strongest ideas from the supplied examples into Ask Intros without replacing its editorial identity, current Home content, private data model, or existing workflows.

## Public Home
- Refine the existing first screen with the supplied polished agency-style rhythm: clearer navigation balance, stronger entrance motion, and more deliberate transitions while retaining the current Ask Intros logo, portrait, wording, login, demo, whitelist, and founder-story links.
- Add a dark asymmetric capability grid inspired by the supplied animated tiles, rewritten around real Ask Intros capabilities rather than generic typography/CDN claims.
- Use meaningful motion for relationship context, adaptive interface, timely signals, security, and mobile access, with cobalt for actions and restrained amber for live intelligence.
- Respect reduced-motion preferences and keep all imagery unique.

## Calendar
- Preserve Month, Week, Day, and Agenda views and add a fifth **Timeline** view.
- Build the timeline from the existing private calendar events: rows grouped by event type, hour markers, current-time indicator, adjustable visible range, and drag-to-move across time and type.
- Reuse the current create/edit/delete event panel and persistence so changes made in Timeline immediately appear in every other calendar view.
- Keep the timeline usable by touch and keyboard, with horizontal scrolling on smaller screens and clear drop feedback.

## Technical details
- Use the project’s existing React/TanStack structure and semantic Aetheris tokens; no external images, paid services, or outside calls.
- Add only a compatible animation/drag dependency if the current project does not already provide one; otherwise use the existing stack.
- Keep the supplied code as a design and interaction reference rather than pasting incomplete fragments or importing its unrelated demo data.
- Update the project roadmap for this multi-part change.
