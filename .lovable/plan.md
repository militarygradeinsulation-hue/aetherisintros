# Simplify navigation and page flow

## Goal
Make Aetheris Intros calmer and easier to move through while preserving every existing capability and route.

## Changes
- Reduce the always-visible navigation to Home, Network, Opportunities, Messages, and More.
- Consolidate search, profile, Briefing Mode, capture, and posting actions into one compact utility menu, while keeping one prominent search control.
- Remove repeated “related tools” strips from page tops; the same destinations remain searchable and pinnable in More.
- Simplify Network and Opportunities hubs into fewer, clearer sections, with less-used capabilities grouped under one expandable area.
- Make the right context panel optional instead of permanently occupying space, and avoid repeating actions already available in page content.
- Reduce visual density through clearer spacing, quieter borders, fewer simultaneous labels, and compact action groups.
- Keep all current data, routes, interactions, responsive behavior, and the Aetheris ivory/dark visual system.

## Verification
- Check primary journeys on desktop and mobile: Home → Network → person → message; Opportunities → need; More → secondary page.
- Verify menus, drawers, search, profile access, and page actions work without overlap or horizontal clipping.
- Confirm the preview builds cleanly and no capability becomes unreachable.
