# Member business tools

Adapts the 24 supplied Aetheris Universe HTML tools into Ask Intros Business Tools under My Work. Existing executive tools remain in adjacent tabs. The original package's seeded random severity and money estimates are not imported.

Every tool supports a deterministic, editable working draft. Sales scripts, follow-up sequences, social drafts, image briefs, text extracts, and the 30-day calendar have specialized builders. Other content tools generate structured drafting instructions; reviews generate evidence worksheets with explicit unknowns. Optional refinement uses the existing RouteLLM service only; no Lovable editor or AI gateway credits are used by these tools. Website reviews do not silently crawl URLs. Image Brief Studio produces prompts, not image files.

The authenticated server verifies the caller has a profile. Documents save to `business_tool_drafts`, with owner RLS, no anonymous permissions, size bounds and optimistic version checks. A failed save preserves the working document. Documents are not published or sent by these tools. Production RLS was checked with a rolled-back two-account test and no test drafts remain.

Commons Trust: the provided digest builder is integrated with canonical followed relationships and visible, non-demo, network posts from the last seven days. It is an on-demand in-app digest. Circle forwarding brakes, portable identifiers, follower move notices, full-account archives and scheduled digest emails are not enabled by this release. Those require protocol decisions and separate server workflows; their guarantees are not advertised.

Onboarding now appears in menus and Butler. New accounts created within seven days receive a one-time Butler invitation on this browser. The shared view switch appears in the top navigation and Butler without remounting member data or consuming a separate page row.

Own posts have text/detail editing and confirmed deletion in the canonical feed. Writes are author-filtered and checked for server acknowledgement. Media and audience remain unchanged while editing. Failed edits retain text.

Voice conversation uses the existing speech recognition, assistant and private ElevenLabs output. Talk with Butler starts on request, enables spoken replies and alternates speaking/listening. Microphone errors are visible and do not restart indefinitely. A voice recording or confirmed existing clone ID is still needed to establish that the configured shared voice is Joseph's actual voice.
