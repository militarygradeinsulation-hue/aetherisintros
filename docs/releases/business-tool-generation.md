# Business tool generation

All 24 catalog entries now use complete-deliverable prompts through the existing RouteLLM integration. Manual working templates remain available separately. Website Review, Brand Contradictions, Business Review, Friction Audit, Executive Report, Competitor Comparison, Meeting Intelligence Brief, Value-First Outreach, and Evidence Review capture their requested public URLs through the existing Specter reader before analysis. Source URLs, timestamps, and capture limitations accompany results. No full-site crawling, speed measurement, revenue-loss calculation, or unobserved fact is claimed. Without the writing provider, website capture still returns a factual source report.

Image Studio and Creation Studio expose a real authenticated image-generation request, PNG preview, and download. They require a server-side OPENAI_API_KEY; BUSINESS_IMAGE_MODEL is optional and defaults to gpt-image-2.5-flare. This is a direct provider integration and does not use Lovable AI credits. Provider failures preserve existing work. Images are session-local and must be downloaded; private text saving does not save image binaries. The interface explicitly explains this. Never put provider keys in client variables or source control.

Tool Generator requests a complete standalone HTML mini-tool for source download. Generated code is never executed in the member workspace. Review code before opening or deploying it. No tool automatically sends campaigns, publishes posts, or deploys generated software.

Production prerequisites: ROUTELLM_API_KEY for AI writing and analysis; OPENAI_API_KEY with image-generation access for images. An environment-variable presence check controls available actions, but is not proof of account quota or model access. End-to-end paid provider operation must be checked with an authenticated member after configuration. Website access can be blocked by the destination or reader, and these failures are reported without synthetic findings.
